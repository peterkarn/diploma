# ☕ Кава на всіх — складчина на MadHeads

Організатор створює замовлення (картка / банка, адреса доставки, мінімум пачок), надсилає друзям одне посилання.
Кожен вставляє посилання на каву з MadHeads, вказує імʼя й кількість — і бачить, скільки скинути. Організатор бачить, хто що бере, відмічає оплати й копіює зведення для оформлення.

## Запуск локально
Потрібен лише Node.js 18+ (залежностей немає):

    node server.js        # http://localhost:3000

Дані зберігаються у `data/data.json`. Тест: `npm test`.

## Hetzner
    git clone <repo> && cd <repo>
    docker compose up -d --build        # порт 3000, дані в ./data

Для HTTPS поставте перед ним Caddy: `caddy reverse-proxy --from your.domain --to localhost:3000`.
Без Docker: `PORT=80 node server.js` (або systemd-юніт із `node server.js`).

## Нотатки
- GitHub Pages не підходить: потрібен спільний стан (сервер).
- Назва/ціна/фото читаються зі сторінки товару (JSON-LD / OpenGraph). Якщо не вийшло — поля можна заповнити вручну; ціну можна виправити на оптову.
- `ALLOWED_HOSTS` обмежує, з яких сайтів сервер тягне сторінки (за замовчуванням — домени з «madheads»).
- Адмінське посилання (`#key=…`) зберігається в браузері організатора; можна скопіювати з панелі.
